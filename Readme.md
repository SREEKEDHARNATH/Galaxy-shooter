#Galaxy shooter

This is a galaxy shooter game you have to take down asteroids
All is hand drawn

download appimage and run chmod +x the appimage and ./appimage
keycontrols wasd or arrow keys

mouse controls(alpha not recommended) left click to go left and right button to go right
scroll to go up and down scroll dont reset untli you middle click

Goal 100 score

All arguements
--------------

-cheat=on    : enables cheats

-mute=on     : mutes

-file=on     : enables file saving

-key=on      : enables keycontrols

-mouse=on    : enables mousecontrols

-verbose=on  : enables logging of arguements


-cheat=off   : disables cheats

-mute=off    : unmutes

-file=off    : disables file saving 

-key=off     : disables keycontrols

-mouse=off   : disables mousecontrols

-verbose=off : disables logging of arguements


-discard-arguements : disables all arguements provided
